Below are my findings while testing. You need to go through all of these, analyse, troubleshoot, fix, verify and test to confirm the fix. Do not guess, rather do test and confirm the fixes.

1. Jobs:
- No way to delete any job. Must have the option to delete any job.

2. Bills:
- If any job has invoice number, that invoice value must come to the Bill when selecting the C-Number while creating any bill in the Commission on the Invoice Value's "invoice value" field.

- If any Bill has "Attach Additional Letter", after creating the bill whether issued or in draft state, only "Edit Letter" option is there, but it needs to have options of "Edit Letter" and "Amend Bill" and "Delete Letter" and "Cancelled Bill" option as well. User must be able to edit/update, cancel both bill and letter. Do not just fix and guess, test every possible options with draft, issued and with any other possible options and combinations.

- For all bills option, instead of loading more bills, should we use pagination? Please consider future scope when there will be thousands of thousands of bills and then pagination probably can be a better option. So think deeper and then decide whether to stick with load more bills option or go with paginations.

- On Bills Page the first field of "C Number, invoice no or bill number" field doesn't load the list while searching. If it is not loaded based on what is giving in to that field as input, then it is almost impossible to memorise the whole number. The list must load based on the input.

- For the last bill as the latest one, if no other new bill is there on top of it, then user must be given a chance to delete the bill to use the same bill number if he does mistake while creating the bill. If you don't give him a chance to delete it, if he makes any mistakes, then he needs to cancel the bill and can't be able to use the bill number anymore. So, you need to keep that in mind and make changes accordingly.

- Also, Amend Bill doesn't give the user any chance to add/remove any fields. It must take the user to the bill creation window so that he can make all kinds of changes the same way he can create a bill. So, that amend bill gives the user every option to make changes on the bill, just like creating a new bill. Hope you understand the issue here.
